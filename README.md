#Push Button LED Brightness Controller
##Description

This arduino priject controlls LED brightness using 2 push buttons.

-Button1->Increase Brightness
-Button2->Decrease Brightness

##Components
-Arduino Uno
-LED
-2 Push buttons
-3 resistors

##Working
The program reads the state of two pushbutton using digitalRead().

When Button 1 is pressed, the brightness value increases.
When Button 2 pressed, the brightness value decreases.
